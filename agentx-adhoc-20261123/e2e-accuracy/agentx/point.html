AISim - E2E Accuracy

Ad-hoc preview, generated locally on 2026-11-23. This is not the production Gym.
  • The AgentX tab uses replays with unmerged CPU-overhead modeling: engine.tokenization plus engine.extra_cpu_overhead (ai-dynamo/aisim#930, #932, and held wiring). The production page doesn't have these yet.
  • Each model has two entries:
    • Op-based + CPU overhead: the op-level model, as main will have it once these PRs merge.
    • Learned FPM + CPU overhead: a frozen GBDT trained on our step captures.
  • GLM-5.3 (SGLang 0.5.20, official points):
    • Tokenizer cost is 1.217 µs/token, measured on SGLang 0.5.21 on the B300 host.
    • No fixed HTTP overhead has been measured for SGLang, so none is applied.
    • The learned model was trained on MTP-on step captures. The learned-plus-MTP replay gate is relaxed locally.
  • Qwen3.5 (vLLM 0.31.0, 6 self-collected lanes):
    • CPU overhead is 1.436 µs/token of tokenization, plus 29.5 ms and 0.245 µs/token of extra overhead.
    • The extra overhead was fitted on lanes 1 and 4, so those two lanes are in-sample.
  • Metrics: all errors are unsigned, closed-loop and computed over matched requests. Each cell is mean ± bootstrap standard error (1,000 resamples).
    • e2e error: |mean predicted / mean silicon − 1| over the requests.
    • Per-request quantile error: across per-request latencies, the mean of |Qpred/Qsil − 1| over p5, p10, …, p95.
    • Silicon requests with TPOT under 1 ms (burst delivery) are excluded from TPOT, and the count is shown.
    • Output-throughput error is the point error, shown as a supplementary column.
    • Per-request MAPE was dropped. Anchored per-request error isn't run here; it's a diagnostic only.
  • The Overview tab is an unchanged copy of the live main snapshot.
